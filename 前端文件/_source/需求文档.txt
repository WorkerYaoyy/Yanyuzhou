1. 产品概述
1.1 产品定位
研宇宙是面向高校科研场景的可信 AI 科研工作台，覆盖「研究可行性分析 → 文献综述 → 数据分析 → 论文写作 → 选刊投稿 → 模拟评审 → 成果导出」的科研全链路。

8. 非功能需求
8.1 安全与合规
传输 TLS 1.3+，存储 AES-256，等保三级（登录页明示）。
L1 / L2 数据默认不进入任何模型训练；敏感字段强制脱敏后方可继续（登录页明示）。
数据分级在「P2-3 项目设置」中设定：L0 公开 / L1 个人（脱敏，仅项目成员可见） / L2 敏感（强制脱敏 + 加密 + 水印溯源）；级别联动 P4 数据导入拦截与 P8 导出校验。
AI 生成内容合规依据：《人工智能生成合成内容标识办法》、GB 45438-2025、《生成式人工智能服务管理暂行办法》、《个人信息保护法》。
所有 AI 生成内容导出时自动携带标注记录与生成记录，不可移除核验标识（P8 明示）；AI 标识覆盖率目标 100%。
关键操作（导出放行、删除、版本回滚）需二次确认并留痕（后端审计能力）。
8.2 可复现性
分析在沙箱执行，产出 run_id、运行环境指纹、程序许可证（示例 MIT）。
支持导出 Python / R 代码包（ZIP） 复现分析（P4 / P8）。
8.3 可观测性
后端保留全流程审计日志（导出、拦截、审批、变更等事件），支撑溯源。
8.4 性能与交互
列表接口分页；AI 长任务异步化并提供进度（推荐 SSE）。
文稿编辑采用乐观锁（version）防并发覆盖。
顶栏导航常驻、切换不闪断；主导航 active 随页面自动切换。
